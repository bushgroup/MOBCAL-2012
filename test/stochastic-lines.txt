# Output lines whose values depend on the pseudo-random number stream.
#
# One POSIX extended regular expression per line. Blank lines and lines
# starting with '#' are ignored. test/regression.sh deletes every matching line
# from both the reference and the freshly generated output before comparing what
# remains character for character.
#
# THE DEFAULT IS "MUST MATCH". A line that is not listed here is required to be
# byte-identical to the reference. That direction is deliberate: when a later
# change adds a new output line, the gate fails and someone has to look at it,
# rather than the new line quietly landing in an ignored bucket. If a new line
# really is stochastic, add it here in the same commit that introduces it, and
# say so in the commit message.
#
# "Stochastic" here means "varies with the random stream", not "varies run to
# run". At a fixed seed on one platform every line below reproduces exactly.
# They are separated out because floating-point summation order is not
# guaranteed identical across compilers and platforms, and these are the lines
# built from long accumulations over hundreds of thousands of trajectories.
# The cross sections among them are checked numerically, with a tolerance, in
# tier T2 -- they are excluded from the exact comparison, not from the gate.
